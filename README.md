# SURVIVE MIN

This directory contains the static export files for the SURVIVE MIN deployment.
This README is regenerated after each build so it is not lost.

## About

SURVIVE MIN is a fan-developed horror visual novel built around one intimate danger: Min is close, Min is watching, and every answer can change the mood of the room.
The game focuses on dialogue pressure, unsettling romance, and psychological horror rather than loud action.
It works best when played slowly, paying attention to tone, timing, and how each choice reshapes your relationship with Min.
